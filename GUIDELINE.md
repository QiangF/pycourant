# keyward class argument variable name convention:
1. lower cased word is separated with "_".
2. keep camel-case when capital character has special meaning.
3. lower case character and superscript or subscript is separated with "_".
4. superscript is placed before subscript, and are separated with "_".

# glossaries 
1. add new variable name to glossaries directory, and keep variable name consistent.

# argument order
1. place keyword argument in the order of appearance.
2. assign a default value (comment "user" on the right to distinguish from vendor default), to keep with python rule: default arguments must go last.
